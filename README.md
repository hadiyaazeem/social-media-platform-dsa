Console Social Media Platform 
A complete console-based Social Media Platform developed in **C++** as a **Data Structures & Algorithms (DSA) Semester Project**.
This project demonstrates the practical implementation of multiple DSA concepts including:
- AVL Trees
- Hash Tables
- Graphs
- Queues
- Stacks
- Linked Lists
- BFS & DFS Traversals
The platform simulates real-world social media functionalities such as user management, posts, stories, messaging, notifications, analytics, and friendship networks
#  Features
##  User Management
- User Registration & Login
- Search Users
- Delete Account
- Display All Users
- Hash Table Based User Storage
##  Social Network (Graph)
- Add Friends
- Remove Friends
- View Friend List
- BFS Traversal
- DFS Traversal
Friendships are implemented using adjacency lists.
##  Posts & Feed
- Create Posts
- Delete Posts
- Like Posts
- Navigate Feed
- Doubly Linked List Implementation

---

##  Stories
- Add Stories
- View Stories Feed
- Circular Linked List Implementation

---

##  Notifications
- Queue-Based Notification System
- Peek Notification
- Process Notifications
- FIFO Implementation

---

##  Messaging System
- Send Messages
- View Latest Message
- Display Conversations
- Stack-Based Message Storage

---

##  Analytics & Ranking
- Top K Active Users
- Top K Liked Posts
- AVL Tree Based Ranking
- Range Queries
- Sorted User/Post Analytics
